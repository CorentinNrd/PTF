CareerHub

Une plateforme de suivi de candidatures, reliée à son API et à une extension Chrome.

Le projet

CareerHub centralise le suivi des candidatures : le tableau de bord permet de gérer les offres et leur statut. L’extension Chrome extrait le titre, l’entreprise, la localisation, le salaire et la description d’une annonce pour l’ajouter au compte via l’API.

Technologies

Application web
  • Vue 3
  • Vuetify
  • Pinia
  • Vue Router
  • Vite
API
  • Node.js
  • TypeScript
  • Express
  • MongoDB / Mongoose
  • JWT
  • Swagger
Extension Chrome
  • JavaScript
  • Chrome Extension API
  • Manifest V3
