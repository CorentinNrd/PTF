# Portfolio de développeur

Portfolio statique en HTML, CSS et JavaScript, servi et compilé avec Vite, sans framework front-end.

## Démarrer

```sh
npm install
npm run dev
```

## Commandes

- `npm run dev` : démarre le serveur de développement.
- `npm run build` : génère le site dans `dist/`.
- `npm run preview` : prévisualise la version compilée.

Pense à remplacer le nom, la ville, les projets et l’adresse e-mail dans `index.html`.
